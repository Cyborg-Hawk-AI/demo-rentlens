## Product specification

**Target customer:** Independent landlords and small real estate investors managing 2–20 rental properties

### Core MVP features
- CSV/spreadsheet import wizard plus bank feed connection to auto-categorize income and expenses per property
- Per-property P&L, cash-on-cash return, and vacancy rate calculated automatically each month
- Tenant ledger: rent due, paid, overdue with automated reminder SMS/email drafts
- Maintenance log linked to expense records so repair costs appear in property P&L
- AI-generated monthly owner report PDF summarizing portfolio health and flagging underperforming properties

**Pricing:** Flat monthly subscription tiered by property count at $29/mo (up to 5 properties), $59/mo (up to 20 properties), $99/mo (unlimited)

**Go-to-market:** Reddit r/realestateinvesting, r/landlord, BiggerPockets forums, YouTube ads targeting 'rental property spreadsheet' searches

**Competitive landscape:** Stessa is free but limited on analytics depth; Buildium and AppFolio are enterprise-priced and complex; no AI-narrative reporting tool in this niche

**Agentic automation plan:** Agent runs on 1st of each month: pulls transactions, categorizes via fine-tuned classifier, computes per-property KPIs, generates PDF report, emails to landlord — zero manual steps after initial setup

**MVP estimate:** Next.js + Supabase + Plaid for bank feeds + self-hosted LLaMA for report generation; 3–4 weeks for MVP with CSV import and manual bank entry before Plaid integration

## Local development

### Prerequisites

- Node.js 18.17 or later
- npm 9+

### Setup

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # production build (required before deploy)
npm start      # serve production build locally
```
